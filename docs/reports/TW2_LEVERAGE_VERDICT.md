## 裁決：使用者選定的 50/50 平衡版 → FAIL（兩條件皆不過）

```text
預先登記主張（平衡版 f=50%，扣 ETF 全成本）：
  L1（報酬）  CAGR(策略) ≥ CAGR(0050 含息)
  L2（回撤）  MaxDD(策略, 含 2008 合成) ≤ MaxDD(0050 含息, 含同一 2008)

裁決跨度 2003-06 → 2025-07（holdout 前，含 2008 合成）：
  L1： 9.68% ≥ 11.37%   → FAIL（反而輸大盤 1.69pp/年）
  L2： 56.01% ≤ 55.75%  → FAIL（回撤反而略高於大盤）

整體：FAIL。50/50 平衡版既沒贏大盤、回撤也沒比較低。
```

**為什麼「平衡槓桿」聽起來好卻失敗**：50% 正2 ≈ 1x 市場曝險，但槓桿套件本身每年
拖累 ~3.8%（費用 + 追蹤 + 波動耗損），加上 50% 現金 0% 收益的拖累，把再平衡紅利吃光，
淨結果**低於**直接買 0050。而且季度再平衡在 2008 那種長空頭裡會「越跌越買」槓桿套件
（每季把現金補進下跌的 2x），把回撤加深到和大盤一樣——這是槓桿產品再平衡的已知陷阱。

## 這份資料揭露的鐵律

```text
槓桿用「超比例的回撤」換「CAGR」：
  想贏大盤報酬？ → 70%/100% 正2 做得到（+5~8pp/年），但 2008 級崩盤 −70~84%。
  想回撤 ≤ 大盤？ → 只能 50/50，但報酬「低於」大盤。
  「無腦、贏大盤、且回撤 ≤ 大盤」三者兼得 → 資料證明不存在。
```

回撤驗證（2008 GFC 子窗，機制拆解）：
- 50/50 季度再平衡：MaxDD 56.0%（越跌越買槓桿，加深回撤）
- 50/50 完全不平衡：2008 內 44.0%，但全跨度飄到 65.3%（槓桿長期複利到主導投組）
- → 無論平不平衡，50/50 槓桿產品全循環回撤都 ~56-65%，**回撤 ≤ 大盤這條路封死**。

## 誠實建議（依你真正要的）

1. **要真無腦、要最好的風險調整報酬、不想虧超過大盤** → **就買 0050（或 006208）**。
   對「回撤 ≤ 大盤」這個約束，0050 本身就是誠實的贏家——這次是「用槓桿實測比過、
   證明沒有更好的無腦選項」，不是憑感覺。
2. **能忍 2008 級 −70~84% 且保證不會恐慌賣在最低點** → **70-100% 00631L 買進持有**
   （不要 50/50、不要季度再平衡進場）。這是真實、有結構性證據（逆價差 roll）的
   贏大盤方法，代價是災難級回撤。**只有你確定能抱過 −80% 才選**。
3. **唯一可能同時要到「槓桿報酬 + 較低回撤」的未證實候選**：趨勢守衛槓桿
   （正2 站上 200 日線才持有、跌破換現金）。但它重新引入了已被裁決 FAIL 的擇時、
   且成本被 2x 放大、需自己的預先登記實驗（計入 N）。我可以下一步做，但誠實預期：
   洗價問題會比 0050 版更嚴重，大概率也 FAIL。
