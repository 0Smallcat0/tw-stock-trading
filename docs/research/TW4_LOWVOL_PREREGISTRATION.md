## 0. 為什麼做這個實驗（脈絡）

TW3 全候選空間掃描把因子選股（品質/低波動/價值）列為**唯一沒被證偽**的路線
（其餘：動能、價值、高股息、法人籌碼、資產配置、擇時 — 全部 REFUTED）。
今日 GitHub／FinLab 生態普查進一步顯示：因子在「只看原始報酬」下對 0050 有邊際
優勢（FinLab 自家 19 年 15.4-19.9% vs 13.7%），但**沒有任何公開專案在「扣成本 +
倖存者-free + 樣本外」下驗證過它**。使用者（求真取向）選擇由本專案親手用**自建、
keyless、倖存者-緩解的 FinMind 宇宙**把這條路驗到底、不留懸念。

本實驗**不是**要「找到能賺的方法」——依全部既有證據，誠實預期是 F2（回撤）FAIL。
本實驗是要：用我們自己的乾淨(er) 資料，對這個最後候選做一次**預先登記、可稽核**的
獨立裁決，讓結論是「驗過」而非「猜的」。

## 2. 宇宙（UNIVERSE）— 倖存者-緩解，誠實揭露殘餘漏洞

主檔清單 = FinMind `TaiwanStockInfo`(type∈{twse,tpex}, 4 位數普通股碼 `^[1-9]\d{3}$`)
∪ `TaiwanStockDelisting`(同碼型) ≈ **2,249 檔**。逐檔抓全生命 `TaiwanStockPrice`
（收盤 + `Trading_money` 成交值）。下市股價可抓（已驗 3662 樂陞 700 根、90.3→13.2），
故下市名回補後**留在**宇宙直到其最後交易日 = 倖存者-緩解。

**殘餘漏洞（誠實揭露）**：FinMind 免費下市清單不完整——已證 3662 樂陞（2016 重大
地雷下市）不在 Info 也不在 Delisting。故本宇宙為**倖存者-緩解**而非完全 free；
仍有未知數量（估數十檔）下市失敗股在兩個清單皆缺。

**偏誤方向不對稱論證（使結論穩健）**：倖存者偏誤**只會美化**報酬（漏掉的都是輸家）。
因此：
- 若本（緩解版）回測對主張 **FAIL** → 真正 free 版只會更差 → **FAIL 為 a fortiori 穩健**。
- 若本回測 **PASS** → 必須加註「殘餘倖存者可能美化」的但書，PASS 不可全信。
低波動策略對此漏洞尤其不敏感：地雷股崩跌時波動飆升，低波動篩選傾向在崩跌前就排除它們；
再加 §3 流動性閘門排除微型股（下市失敗股集中處）。

排除：ETF/權證/存託憑證/特別股（碼型 + 名稱過濾）、emerging 板、每日成交值閘門不過者。

## 3. 因子與組合建構（LOCKED — 先驗選定，禁止事後改）

**單因子：低波動（low-volatility）。只驗這一個，不做因子 fishing**
（避免 FinPilot「150 選 5」式 multiple-testing）。

主 config（primary，裁決以此為準）：
- **波動度量**：過去 **252 交易日**原始收盤簡單日報酬的標準差；每日報酬先夾在
  ±10%（台股漲跌幅上限）以中和除息/分割造成的單日跳空假訊號。
- **選取**：符合資格者中，波動由小到大取 **N=50** 檔（對標 0050 的 ~50 成分）。
- **加權**：**等權**（1/N）。
- **再平衡**：**月頻**，每月最後交易日依當日收盤選股，隔一交易日開盤成交（T+1 lag，
  避免前視）。
- **資格閘門**（每個再平衡日、僅用當日及以前資料）：
  1. 流動性：過去 60 交易日**每日成交值中位數 ≥ NT$50,000,000**（排除吃不到的微型股）。
  2. 資料充足：該日往前 ≥ 252 個交易日有價。
  3. 價格 ≥ NT$5（排除水餃股）。
  4. 屬 §2 宇宙且當日有正常交易（非停牌/下市後）。
- **報酬計算**：持有名單用**還原總報酬**（自 `TaiwanStockDividendResult` 的
  before_price/reference_price 建除息+分割因子，沿用 src/data/adjustments.py 機制）；
  換手時對賣出腿計證交稅、雙邊計手續費與滑價（§5）。停牌/下市：持有中個股若下市，
  於最後交易日以最後價變現計入（含下市崩跌），不假設無損出場。

## 4. PBO/CSCV 網格（GRID — 亦於跑前宣告；用於過擬合檢定，非事後選美）

在主 config 外，宣告以下鄰域配置一起跑，餵入 `probability_of_backtest_overfitting`
的 T×N 報酬矩陣，量測「樣本內最佳是否樣本外仍最佳」：
- N ∈ {20, 50, 100}
- lookback ∈ {126, 252}
- 加權 ∈ {等權, 反波動(1/σ)}
共 3×2×2 = **12 配置**（含主 config）。此網格在此凍結；不新增、不挑選。
每個配置各登記為一個 trial（N 由 9 續接至 21）。

## 5. 成本模型（LOCKED，沿用既有 TW 模型）

- 手續費：0.1425% × 折扣 0.6 = **0.0855%**／腿，單筆下限 **NT$20**。
- 證交稅：**賣出腿 0.3%**（個股；本宇宙為個股非 ETF）。
- 滑價：**每腿 15 bps**（低波動大型股保守估；另於敏感度記錄 0 與 30 bps）。
- 現金（未投入或不足 N 檔時）：年化 1.0% 計息（保守）。
- 全部以換手 delta 計費（僅對買賣變動部位收費）。

## 6. 閘門與 PASS/FAIL 規則（LOCKED）

1. **主張 F1 ∧ F2**（§1）：裁決跨度上成立。
2. **過擬合 PBO ≤ 0.05**（§4 網格，CSCV，block_count=16）。
3. **DSR ≥ 0.95**：主 config 日報酬，effective_trials = 登記後 N，
   trial_sharpe_variance 由 registry 年化 Sharpe 去年化（既有 `non_annualized_sharpe_variance`）。
4. **holdout**：主裁決全程只用 2025-07-03 之前；holdout 僅在 F1∧F2∧PBO∧DSR 全過後，
   **一次性**揭露 out-of-sample 表現且不得據以回頭調參。任一前置閘門未過即 FAIL，
   holdout 保持鎖定不動用。

任一閘門不過 ⇒ **FAIL**，不建 runtime。缺陷 trial（若跑出後發現定義錯誤）**保留**於
registry（append-only，N 單調不減），不得刪改。
