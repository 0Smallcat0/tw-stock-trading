# 多引擎跨市場配置器 — 研究（MEF Research）

日期：`2026-07-05`
目標：實作框架最終形態——把多個**低相關的報酬引擎**（TW 槓桿 beta、crypto 趨勢、
US 疊溢價、管理期貨、黃金）組成一個投組，用**穩健定量 + 分數 Kelly 槓桿**最大化
長期幾何成長。承接三份 max-return 研究（crypto/TW/US）＋本地實證。
狀態：研究階段。此檔為研究結論；規劃與預先登記另立。

## 0. 框架與目標函數（承接三市場地圖）

> 最大長期幾何成長 **g ≈ r_f + Sharpe²_組合 / 2**。

單一引擎的 Sharpe 有上限（TW ~0.65、crypto 趨勢 ~1、US beta ~0.5）。唯一能把
**組合** Sharpe 拉高的免費午餐是**組合不相關的引擎**（SR²_組合 = Σ SR²ᵢ，若完全不相關）。
所以最終形態 = **(1) 蒐集低相關引擎把組合 Sharpe 拉高 →(2) 分數 Kelly 槓桿**。

## 1. 配置數學與「估計誤差」這道真正的牆

- **多變量 Kelly（連續形式）**：最佳槓桿向量 **f\* = Σ⁻¹(μ − r_f)**；對應最大成長
  = ½·(μ−r_f)ᵀ Σ⁻¹ (μ−r_f) = ½·Sharpe²_組合。這需要 μ（期望超額報酬）與 Σ（共變異）。
- **致命問題：μ 和 Σ 是估計值、極 noisy**。naive Kelly / 均值變異最佳化（MVO）會
  **放大估計誤差**——把雜訊當訊號、押上槓桿，樣本外崩掉。這正是 **QSPIX 教訓**
  （AQR 目標 Sharpe 0.70、實現 0.41、−41% 回撤）的數學根源，也是 DeMiguel et al.
  「1/N 很難被 MVO 打敗」的原因。
- **穩健對策（本專案採用）**：
  1. **不用 naive MVO/full Kelly**；改用 **風險平價（risk parity / inverse-vol）**
     為主——它**不需要 μ 估計**（最脆弱的部分），只需相對波動，穩健得多。
  2. **共變異用 shrinkage**（Ledoit-Wolf 向常數相關收縮），降低樣本共變異的雜訊。
  3. **分數 Kelly（半 Kelly）**：拿 ~75% 成長、換一半波動；且對估計誤差有安全邊際。
  4. **1/N 與風險平價作為 baseline**，任何更複雜的配置必須在**樣本外**打敗它才採用。
- 結論：**配置法先驗鎖定為「shrinkage 風險平價 + 半 Kelly 槓桿上限」**，不做
  return-forecast 型的 MVO（那是把估計誤差請進門）。

## 2. 實證：引擎「真的」有多不相關（本地資料，載重證據）

月報酬相關（本地 0050 全史 + Binance BTC/ETH/SOL）：

| | 0050(TW) | BTC | ETH | SOL |
|---|---|---|---|---|
| 0050(TW) | 1.00 | **0.17** | **0.20** | **0.13** |
| BTC | 0.17 | 1.00 | 0.72 | 0.51 |
| ETH | 0.20 | 0.72 | 1.00 | 0.61 |
| SOL | 0.13 | 0.51 | 0.61 | 1.00 |

各資產（自身月史）年化：0050 CAGR 17.0%/vol 19.5%/**Sharpe 0.81**（23 年）；
BTC 66.6%/70.5%/0.74、ETH 76.1%/95.0%/0.61、SOL 321%/180%/0.85（僅 2020-26，
爆發期，**不可外推**）。

**兩個決定性發現：**
1. **TW ⊥ crypto ≈ 0.13–0.20**——真低相關。組合兩條 Sharpe~0.75、ρ=0.18 的流，
   組合 Sharpe ≈ 0.75×√(2/1.18) ≈ **0.98**（+30%，g_max 從 0.28 → 0.48，近翻倍）。
   **框架對 TW+crypto 這對，實證成立。** ✓
2. **Crypto 是「一個」引擎，不是三個**（BTC/ETH/SOL 互相 0.5–0.72）。多加幣種
   ≠ 分散；用**單一** crypto 流即可（趨勢版 Sharpe > buy-hold）。

（US 相關性未能本地驗證，見 §4 資料問題；但 US 研究報告已外部證實：US 股與台股
~0.5–0.7 相關[只是溫和加分]，而**管理期貨 ~0 相關、黃金 ~0 相關**才是真正的分散引擎
——DBMF 在 2022 年 60/40 −20.8% 時 +31.6%。）

## 5. 誠實可達上限（含估計誤差 + 真相關 + 成本）

理想（全不相關）會給組合 Sharpe 1.1+；但**真相關不是 0**（股票類彼此 0.5–0.7），
且**估計誤差把實現 Sharpe 砍 30–40%**（QSPIX base rate）。誠實落點：
- **組合 Sharpe：~1.0–1.3 事前 / ~0.6–0.9 實現。**
- **半 Kelly（~2–3x 總槓桿）→ ~10–15% 淨成長、−25–35% 回撤。**
- 比任何**單一**引擎的風險調整報酬好（TW/crypto/US 單獨都 Sharpe ~0.5–1、回撤更深），
  但**不是暴富模式**。真正的 edge 是**分散 + 定量 + 紀律**，不是 alpha。
- 全球天花板仍是 Medallion（Sharpe ~2、封閉）；本框架合理目標是「~1 Sharpe、半 Kelly、
  鐵紀律」的穩健配置器。

## 6. 反過擬合紀律（多資產有自己的陷阱）

多資產回測的過擬合點：**挑哪些引擎進來、Kelly 分數、再平衡頻率、lookback**——全是
可被 fish 的旋鈕（就是 FinPilot 150 選 5、tw_stocker PBO 0.94 的死因）。故：
- **跑回測前寫死**：引擎集合、配置法（shrinkage 風險平價 + 半 Kelly、槓桿上限）、
  再平衡頻率、成本模型。
- **不 fish**：引擎納入與 Kelly 分數先驗選定；配置法變體須樣本外打敗 1/N baseline 才留。
- **單次 holdout、PBO/DSR、缺陷 trial 保留、registry 續接**（本 repo 現 N=21）。

## 7. 下一步（規劃階段的預先登記草案）

主張（規劃階段定稿、跑回測前凍結）雛形：
```text
策略：shrinkage 風險平價跨引擎組合（E1 TW 槓桿beta + E2 crypto 趨勢 + E4 管理期貨
      + E5 黃金 [+ E3 US beta]），半 Kelly 槓桿（上限先驗），月頻再平衡，扣全成本。
主張：F1 組合 Sharpe > 任一單一引擎的 Sharpe（分散確實加分）
      F2 組合 MaxDD < 最深單一引擎的 MaxDD（分散確實降險）
      F3 樣本外（holdout）打敗 1/N 等權 baseline（配置法有真價值，非過擬合）
閘門：PBO ≤ 0.05、DSR ≥ 0.95、單次 holdout、缺陷 trial 保留。
誠實預期：F1/F2 應過（分散數學+實證相關性支持）；F3 是最硬的一關
      （配置法常敗給 1/N）——這才是這個專案真正在賭的東西。
```

**一句話**：實證證明 TW 與 crypto 真低相關（0.15），框架的地基是實的；最終形態是
「穩健風險平價 + 半 Kelly」的多引擎配置器，賭的是**分散與紀律**、不是 alpha；最硬的
考驗是樣本外打敗 1/N。US 資料源是唯一待解的工程項目（可解）。
