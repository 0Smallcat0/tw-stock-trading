## 一、槓桿路線（00631L 元大台灣50正2）— 最強候選

### 為什麼能贏大盤：兩個真實原因

1. **多頭複利**：2x 每日槓桿在長期上漲市場中複利放大（台股 2014-2026 大多頭）。
2. **台指期逆價差 roll yield（關鍵、反直覺）**：台股高殖利率使台指期長期逆價差，
   近十年 **93% 時間為逆價差**（2013/5-2023/4）。正2 每月轉倉「賣近月買遠月」=
   結構性買低賣高，等於免費吸收每年 3-4% 的隱含股息點數。**這是台灣特有的結構性
   優勢，不是運氣**（來源：UDN 存股族愛ETF、letf.com.tw 期貨價差解析）。

### 實測績效（自建管線 + TWSE 官方原始價交叉驗證）

驗證方法：FinMind 原始價經證實為未還原（2018-01 = 35.37、2026-03 = 526.25 皆與
TWSE 官方 STOCK_DAY 逐筆吻合）；2026-03-31 做過 1:22 分割（官方 TWTCAU：443.15→20.14，
factor 0.04545），已還原。

```text
窗口 2014-10-31 → 2026-07-03（11.67 年，00631L 全生涯）：
  00631L（分割還原總報酬）：42.26x（+4126%）  CAGR 37.82%  MaxDD 55.14%
  0050  （含息總報酬，同窗）： 9.40x（ +840%）  CAGR 21.17%  MaxDD 33.96%
  → 槓桿贏大盤 +16.65pp/年，代價是回撤 1.62 倍
```

逐年報酬（分割還原）：2015 −16.5%｜2016 +39.2%｜2017 +39.8%｜2018 −10.4%｜
2019 +70.9%｜2020 +68.1%｜2021 +62.2%｜**2022 −36.4%**｜2023 +62.9%｜2024 +59.0%｜
2025 +51.0%｜2026 +135.3%（融漲）。

### 致命風險（同樣自建模擬，誠實揭露）

00631L **2014 年才上市，從未經歷 2008/2000 級崩盤**。用 0050 資料模擬每日 2x 產品
（零成本假設，實際更糟）：

```text
2008 GFC 重演（2007-10 → 2009-06）：
  0050 本身   MaxDD 55.8%
  模擬 2x     MaxDD 83.1%（淨值 100 → 最低 18.8）
2022 熊市：0050 −34.0% | 2x −58.0%
2020 COVID：0050 −28.2% | 2x −49.4%
2015 崩盤：0050 −21.0% | 2x −38.9%
```

**−83% 是「無腦」失效的臨界點**：那是人會在最低點恐慌賣出、把帳面損失變成永久損失的
時刻。100% 正2 買進持有是「真實有效但危險」。

### 三個必須誠實面對的偏誤

1. **窗口偏多**：2014-2026 是台股史上最好的多頭之一（AI/台積電）。11.67 年 CAGR
   21%（0050）本身就遠高於長期 10%——這個窗口對槓桿特別友善。
2. **2026 融漲灌水**：2026 單年 +135% 大幅拉高 CAGR，有 recency bias。
3. **未經真正熊市洗禮**：產品壽命內沒有 −58% 級崩盤，83% 模擬回撤是它的未爆彈。

### 可行的風險調節版本（研究支持的中庸路線）

- **50% 正2 + 50% 現金、定期再平衡** ≈ 1x 市場曝險，但有再平衡紅利，
  2008 模擬 MaxDD 從 83% 砍到 ~28%（現金緩衝吸收槓桿）。報酬接近或略勝大盤，
  回撤與大盤相當——**不會「大贏」，但「穩贏一點且睡得著」**。
- **固定 60-70% 正2**：瞄準特定回撤上限（如 ≤50%）。
- 這正是預註冊回測要掃描的 frontier：100% / 70% / 50%+cash 各自的報酬-回撤點。

## 二、法人籌碼跟單 — 次選，證據不足以先做

- **官方資料免費可得**：TWSE T86（三大法人買賣超日報，每股每日，一個請求抓全市場）、
  TWT38U（外資）、TWT44U（投信）盤後 ~16:00 公布——資料不是問題。
- **但學術證據對「可跟單的版本」不利**：
  - Barber-Lee-Liu-Odean（RFS 2009 / JFE 2014）：台灣散戶整體每年輸 3.8%（約 GDP 2.2%），
    贏家是極少數有持續技巧的當沖客——**這群人無法用落後一天的公開資料跟單**。
  - 外資買超的持續性 alpha 多在「當日」，跟單者 T+1 開盤才能進場，大半 alpha 已被吃掉。
  - 隔日沖分點：主力隔日沖是「賣給隔天追高的人」，跟單者正是那個 exit liquidity。
- **券商分點資料 scrape 敵意高**（需逐股請求 + captcha），不適合 keyless 每日系統。
- **裁決**：資料可得但證據薄、T+1 執行摩擦大。可作為未來預註冊實驗，但不是先做的對象。

## 三、為什麼不是選股／個股

（延續前次研究，未翻案）台灣是動能失效的著名市場（Chui-Titman-Wei 2010）；
小型股回測有倖存者偏差（等權灌水 ~62%/年）；個股均線效果在成熟大型股最差（PBFJ 2021）。
選股型系統需要含下市股的全市場資料 + 更兇的防過擬合，證據基礎比槓桿弱。

## 四、預註冊實作設計（TW2，供閘門檢驗）

**主張改寫**（跑正式登記回測前寫死；使用者 2026-07-04 選定「平衡版」= 50% 正2 + 50% 現金季度再平衡）：

```text
產品：買進持有 f% 0050正2 + (1−f)% 現金，季度再平衡，無擇時無訊號。
      使用者選定 f=50%；回測同時掃描 f ∈ {50%, 70%, 100%} 給出 frontier。
主要主張（平衡版 f=50%，兩條件皆須成立，扣 ETF 全成本、現金 0% 敏感度 1.5%）：
  L1（報酬）  CAGR(策略) ≥ CAGR(0050 含息)              「至少不輸大盤」；另報「贏 ≥1pp」為加分
  L2（回撤）  MaxDD(策略, 含 2008 合成壓力) ≤ MaxDD(0050 含息, 含同一 2008)   「回撤 ≤ 大盤」
基準：0050 含息買進持有（同一跨度）。
資料：真實 00631L 2014-10→2026-07 + 合成 2x（0050 含息 TR 建構）2003→2014 含 2008 GFC。
```

**合成 2x 校準（誠實揭露，跑正式回測前定案）**：合成序列 = 2×（0050 含息日報酬）
每日複利 − 校準日拖累。實測真實 00631L 在 2014-2026 重疊段 = 2×TR **減 3.77%/年**
（費用率 ~1.1% + 波動耗損 + 追蹤誤差；真實產品 CAGR 37.8% vs 無摩擦 2×TR 41.6%）。
故合成 pre-history 加入 ~1.53bps/日拖累以匹配真實。此拖累幾乎不影響 L2 回撤檢定
（2008 的 83% 回撤來自 2× 複利本身，非拖累），主要影響 L1。real/syn 追蹤帶 0.77-1.28。

- **通過** → 這是有證據、可實作、閘門背書的「無腦贏大盤」方法，建 runtime（每季再平衡通知）。
- **失敗** → 誠實記錄哪個 f 值在哪個條件破功，給出「你能接受多少回撤 → 對應哪個 f」的對照表。

**可重用**：資料管線、費稅模型（ETF 賣稅 0.1%）、驗證閘門、還原/分割處理全部沿用。
**新增**：合成 2x 序列建構器、槓桿佔比投組（現金緩衝 + 再平衡）、L1/L2 雙主張裁決。
